# capgo-capacitor-trojan

Capgo Cursor plugin focused on production-grade Capacitor and Capgo practices.

## Included

- `rules/`: always-on guardrails for Capacitor architecture, Capgo live updates, security, and testing.
- `skills/capgo-capacitor-architect/`: implementation workflow for feature delivery.
- `skills/capgo-release-auditor/`: release readiness checklist for Capacitor + Capgo apps.
- `agents/capgo-reviewer.md`: reviewer persona that prioritizes risky regressions.
- `commands/`: reusable audit and rollout prompts.
- `hooks/`: shell safety checks that block `npm` and `npx` usage.
